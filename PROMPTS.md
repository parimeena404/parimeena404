# AI Prompts for GitHub Profile Graphics

These prompts are designed for Midjourney, DALL-E 3, or any other high-end AI image generator. The aesthetic is focused on a premium, dark-mode, tech-centric look suitable for an elite developer profile.

## 1. Custom Logo Prompt

**Prompt:**
> A sleek, minimalist monogram logo for the initials "PM" (Pari Meena), designed in a premium tech aesthetic. The logo should feature glassmorphic elements, glowing neon accents in deep violet (#7C3AED) and sky blue (#38BDF8), on a pure dark charcoal or black background. The typography should be sharp, modern, and futuristic. The overall feel should be similar to branding for Apple, Stripe, or Vercel. 8k resolution, vector art style.

## 2. Banner for `CalciSOS` Project

**Prompt:**
> A high-end, dark mode UI/UX presentation mockup for a secure, hidden SOS calculator app named "CalciSOS". The scene shows a sleek mobile phone floating in an abstract, dark environment. The screen displays a minimalist calculator interface with subtle glowing red and purple accents. The background features blurred, glowing code snippets and abstract glassmorphic panels. Premium aesthetic, realistic lighting, 8k, dribbble style.

## 3. Banner for `TrackNest` Project

**Prompt:**
> A beautiful, modern web dashboard mockup for a bug tracking system named "TrackNest". The dashboard is presented in dark mode with a purple and blue color scheme (#7C3AED, #38BDF8). It shows clean graphs, lists of tickets, and sleek UI components. The dashboard is displayed on a floating laptop screen against a dark, elegant background with subtle neon lights. High contrast, highly detailed, Vercel design system aesthetic.

## 4. Banner for `AlgoAssembly` / General C++ Project

**Prompt:**
> An abstract, highly detailed 3D illustration representing complex algorithms and assembly code. Glowing data streams, interconnected nodes, and glowing blue and purple lines (#7C3AED, #38BDF8) on a deep dark background. The image should feel like looking inside a high-tech computer processor or AI matrix. Premium, futuristic tech aesthetic, 8k resolution.

## 5. Background Header Image (Optional)
